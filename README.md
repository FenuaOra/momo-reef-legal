# Momo Reef — legal & support pages

Public because GitHub Pages only serves public repositories. It contains no
source code — the app itself lives in a private repo.

- `privacy.html` — linked from the App Store listing and from the app's paywall
- `support.html` — the Support URL the App Store listing requires

`privacy.html` is generated from `assets/legal/privacy.html` in the app repo.
Edit it there and copy it across, so the version the app links to and the
version under review cannot drift apart.
